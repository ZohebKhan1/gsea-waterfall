GSEA waterfall, volcano, and comparative NES plots

GSEA waterfall, volcano, and comparative NES plots

Standalone R functions for visualizing ranked GO biological-process enrichment results.
Author: Zoheb Khan
Example: GSE122380 GO biological-process GSEA contrasts
Source: ZohebKhan1/gsea-waterfall

1 Overview

gsea-waterfall visualizes precomputed Gene Set Enrichment Analysis (GSEA) results as ranked NES waterfalls, symmetric or directional volcano plots, and cross-contrast NES scatterplots. The functions return ggplot objects without running GSEA, changing supplied statistics, or writing files.

The examples use fixed GO biological-process results from GSE122380 cardiomyocyte differentiation contrasts. Plotting choices control row selection, labels, grouping, and presentation; they do not redefine enrichment significance.

The waterfall layout is inspired by pathway-level figures in Ciceri, Nature, 2024, Xu, Nature Cell Biology, 2025, Vuong, Science, 2026, and Risgaard, Science, 2026.

2 Install and source

Install the plotting dependencies once:

utils::install.packages(c('ggplot2', 'ggrepel', 'RColorBrewer', 'scales'))

Download the shared utilities first, then the plot modules you need:

base_url <- 'https://raw.githubusercontent.com/ZohebKhan1/gsea-waterfall/main/functions'

utils::download.file(paste0(base_url, '/gsea_plot_utils.R'), 'gsea_plot_utils.R')
utils::download.file(paste0(base_url, '/gsea_waterfall_plot.R'), 'gsea_waterfall_plot.R')
utils::download.file(paste0(base_url, '/gsea_volcano_plot.R'), 'gsea_volcano_plot.R')
utils::download.file(paste0(base_url, '/gsea_half_volcano_plot.R'), 'gsea_half_volcano_plot.R')
utils::download.file(paste0(base_url, '/gsea_nes_scatter_plot.R'), 'gsea_nes_scatter_plot.R')

source('gsea_plot_utils.R')
source('gsea_waterfall_plot.R')
source('gsea_volcano_plot.R')
source('gsea_half_volcano_plot.R')
source('gsea_nes_scatter_plot.R')

3 Input contract

Each table represents one GSEA contrast with one row per unique term. The default columns are:

Column Required Meaning
go_description yes GO term description and default matching key
NES yes normalized enrichment score
pval yes nominal GSEA p-value in [0, 1]
padj yes adjusted p-value in [0, 1]

All four columns must be complete, and NES values must be finite. Descriptions must be unique unless id_col names a separate complete, unique term key. Comparative scatterplots use the exact shared-key intersection and do not impute absent terms.

Load the bundled examples from the repository root:

gsea_cardiomyocyte_vs_mesoderm <- read_gsea_result_csv(
  'tutorial/data/GSE122380_gsea_cardiomyocyte_vs_mesoderm.csv'
)
gsea_day9_vs_day6 <- read_gsea_result_csv(
  'tutorial/data/GSE122380_gsea_day9_vs_day6.csv'
)
gsea_day3_vs_day1 <- read_gsea_result_csv(
  'tutorial/data/GSE122380_gsea_day3_vs_day1.csv'
)

4 Ranked waterfall plots

plot_gsea_waterfall() selects one NES direction, ranks terms by NES, padj, or pvalue, and displays the first top_n rows. term_groups controls point colors; label_terms independently controls direct labels. Text seeds are matched case-insensitively against term descriptions, while supplied term IDs are matched exactly after case normalization.

4.1 Positive NES waterfall

positive_term_groups <- list(
  'Ion channel' = c(
    'Calcium', 'Sodium', 'Potassium', 'Ion', 'Voltage', 'Channel',
    'electrical', 'Action potential', 'transmembrane', 'conduction'
  ),
  'Metabolism' = c(
    'Metabolic', 'Metabolism', 'Electron transport chain', 'Mitochondria',
    'Mitochondrial', 'Oxidative', 'Phosphorylation', 'ATP', 'lipid',
    'biosynthetic', 'respiration'
  ),
  'Muscle contraction' = c(
    'Muscle contraction', 'Muscle cell differentiation', 'Striated',
    'Sarcomere', 'Myofibril', 'Actin', 'Muscle'
  ),
  'Heart development' = c('atrial', 'ventricular', 'heart', 'cardiac')
)

positive_waterfall_label_terms <- c(
  'myofibril assembly',
  'cardiac muscle contraction',
  'cardiac muscle cell action potential',
  'calcium-mediated signaling',
  'electron transport chain',
  'muscle cell differentiation',
  'ATP metabolic process',
  'cardiac cell development',
  'cardiac chamber morphogenesis',
  'muscle contraction',
  'cardiac conduction',
  'cardiac muscle cell contraction',
  'heart growth',
  'cardiac atrium development',
  'heart trabecula morphogenesis'
)

positive_waterfall_plot <- plot_gsea_waterfall(
  gsea_results = gsea_cardiomyocyte_vs_mesoderm,
  direction = 'positive',
  top_n = 100L,
  rank_by = 'NES',
  x_label = 'Ranked GO terms by NES for Cardiomyocyte vs. Mesoderm',
  label_terms = positive_waterfall_label_terms,
  term_groups = positive_term_groups

Figure 1. Positive NES terms ranked by NES, with selected cardiac-relevant groups and labels.

5 Volcano plots

Use plot_gsea_volcano() for both NES directions in one panel and plot_gsea_half_volcano() for a larger directional view. The example retains the established adjusted p-value cutoff of 0.05.

5.1 Symmetric volcano

volcano_label_terms <- c(
  'cardiac muscle contraction',
  'muscle cell differentiation',
  'cardiac chamber morphogenesis',
  'heart growth',
  'heart valve development',
  'mitotic nuclear division',
  'DNA replication initiation',
  'mitotic G2/M transition checkpoint',
  'centriole assembly',
  'ribosome assembly'
)

gsea_volcano_plot <- plot_gsea_volcano(
  gsea_results = gsea_cardiomyocyte_vs_mesoderm,
  padj_cutoff = 0.05,
  label_terms = volcano_label_terms,
  contrast_label = 'Cardiomyocyte vs. Mesoderm',
  label_words_per_line = 3L
)

Figure 3. Symmetric NES volcano colored by adjusted-p-value significance and direction.

6 Comparative NES scatterplot

plot_gsea_nes_scatter() compares the exact shared term-key intersection. The fitted line is descriptive; the helper does not calculate a new enrichment statistic.

scatter_label_terms <- c(
  'mesenchyme development',
  'mesoderm development',
  'mesodermal cell differentiation',
  'myofibril assembly',
  'heart process',
  'oxidative phosphorylation',
  'regulation of nuclear division'
)

comparative_nes_scatter_plot <- plot_gsea_nes_scatter(
  gsea_x = gsea_day9_vs_day6,
  gsea_y = gsea_day3_vs_day1,
  x_label = 'Day 9 vs. Day 6 NES',
  y_label = 'Day 3 vs. Day 1 NES',
  color_by = 'significance',
  quadrant = 'all',
  x_name = 'Day 9 vs. Day 6',
  y_name = 'Day 3 vs. Day 1',
  label_terms = scatter_label_terms,
  padj_cutoff = 0.05,
  include_nonsignificant = TRUE,
  equal_axis_limits = TRUE,
  show_fit_line = TRUE
)

Figure 6. Shared terms colored by significance in one, both, or neither contrast.

7 API summary

Function Contract
read_gsea_result_csv() reads and validates one precomputed CSV without filtering rows
plot_gsea_waterfall() returns a ranked one-direction ggplot
plot_gsea_volcano() returns a symmetric NES-versus-adjusted-p-value ggplot
plot_gsea_half_volcano() returns a directional ggplot after the explicit NES boundary
plot_gsea_nes_scatter() returns a ggplot from the exact shared term-key intersection

All plot functions return ggplot objects without writing files. Their source documentation defines the complete argument contracts. Common column arguments are term_col, nes_col, pvalue_col, padj_col, and optional id_col.

8 Reproduce the repository

Install the rendering dependencies and run the maintained scripts from the repository root:

utils::install.packages(c(
  'base64enc', 'bookdown', 'knitr', 'rmarkdown', 'svglite', 'systemfonts'
))
Rscript R/01_generate_gsea_figures.R
Rscript R/02_render_github_pages.R
Rscript R/03_check_gsea_contracts.R

The figure script writes six editable, font-embedded SVGs under tutorial/assets/figures/. The site script renders this source into docs/, and the contract script verifies fixed scientific counts, stable-key matching, and invalid-input boundaries. Maintainers use the canonical R Codex Utils commands in MAINTENANCE.md.
